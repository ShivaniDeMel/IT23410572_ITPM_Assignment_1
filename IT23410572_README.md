# IT23410572 - Test Automation

A test automation framework using Playwright to automate testing for the Pixels Suite Chat Translator application.

## Overview

This project automates test execution for a Singlish-to-Sinhala translation application. Test cases are read from Excel files and executed using Playwright browser automation.

## Features

- **Excel-Based Test Cases**: Load test cases from Excel files
- **Automated Browser Testing**: Uses Playwright for cross-browser automation
- **Flexible Column Detection**: Automatically detects input, expected output, actual output, and status columns
- **Configurable URLs**: Support for custom frontend URLs via environment variables

## Installation

### Prerequisites
- Python 3.7 or higher
- pip (Python package manager)

### Step-by-Step Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ShivaniDeMel/IT23410572_ITPM_Assignment_1.git
   cd IT23410572_ITPM_Assignment_1
   ```

2. **Install Python dependencies:**
   ```bash
   pip install playwright openpyxl
   ```

3. **Install Playwright browser binaries:**
   ```bash
   playwright install
   ```
   This downloads the necessary browser files for Playwright (Chromium, Firefox, WebKit).

## Configuration

### Environment Variables

- `FRONTEND_URL` - The URL of the Chat Translator application (default: `https://www.pixelssuite.com/chat-translator`)

### Test Case Files

Test cases are loaded from Excel files. Default path: `test_automation/Assignment 1 - Test cases.xlsx`

### Column Naming

The script automatically detects the following columns:

**Input Column**: Singlish, Input, Singlish Input, Test Input, Source, Sentence, Text

**Expected Output Column**: Sinhala, Expected_Output, Expected Output, Expected output, Expected, Expected Sinhala

**Actual Output Column**: Actual_Output, Actual Output, Actual output, Actual

**Status Column**: Status, Result

## Usage

### Quick Start

1. **Prepare your test file:**
   - Place your test Excel file in the project directory or `test_automation/` folder
   - Ensure it follows the column naming conventions (see Configuration section below)
   - Default file: `test_automation/Assignment 1 - Test cases.xlsx`

2. **Run the test automation:**
   ```bash
   python IT23410572_test_automation.py
   ```

3. **View results:**
   - The script will open a browser and execute each test case
   - Results are displayed in the console and updated in your Excel file

### Advanced Usage

#### Using a Custom Test File
```bash
python IT23410572_test_automation.py --excel-file path/to/your/test-file.xlsx
```

#### Using a Custom URL
```bash
export FRONTEND_URL=https://your-custom-url.com
python IT23410572_test_automation.py
```

Or on Windows:
```powershell
$env:FRONTEND_URL="https://your-custom-url.com"
python IT23410572_test_automation.py
```

### Command Line Arguments

For all available options:
```bash
python IT23410572_test_automation.py --help
```
